# Instrucciones para Claude en este proyecto

## Idioma (regla permanente)
- **Habla siempre y únicamente en español** con el usuario: respuestas, resúmenes, notas del parche, mensajes de
  progreso y descripciones de los pasos. El usuario no habla inglés.
- Solo se permiten palabras en inglés cuando son el nombre exacto de algo que el usuario verá así (por ejemplo,
  «Change visibility» en GitHub), y conviene explicarlas en español.

## Cada versión
- Entregar el APK firmado y las **notas del parche** en español.
- Publicarla en las Releases de GitHub (CHANGELOG.md + releases/versions.json).
- Cuando se añade una función importante que se queda, actualizar también el README (la página principal de GitHub).
